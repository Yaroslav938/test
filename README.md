# ✅ TaskFlow — Современный веб-сайт «Список задач» (To-Do List)

> Стильное, легкое и полнофункциональное веб-приложение для управления повседневными задачами с сохранением данных в браузере, фильтрацией, поиском, адаптивным дизайном и поддержкой светлой/темной темы.

---

## 🌟 Основной функционал

В соответствии с техническим заданием реализованы все ключевые возможности:

1. **➕ Добавление новых задач**:
   - Быстрый ввод с валидацией (нельзя добавить пустую строку).
   - Выбор категории задачи с цветовой индикацией:
     - 💼 **Работа**
     - 🏠 **Личное**
     - 📚 **Учеба**
     - ⚡ **Срочно**
     - 🎯 **Общее**
   - Добавление по нажатию клавиши `Enter` или клику по кнопке.
2. **✔️ Отметка выполненных задач**:
   - Кастомный доступный чекбокс с плавной микроанимацией.
   - Зачеркивание текста и пересчет счетчиков в реальном времени.
   - Мотивационные сообщения при достижении 100% выполнения.
3. **🗑️ Удаление задач**:
   - Индивидуальное удаление задачи с плавной анимацией исчезновения (`fade-out`).
   - Кнопка **«Очистить завершенные»** для массового удаления всех выполненных дел.
4. **💾 Сохранение задач после обновления страницы (LocalStorage)**:
   - Все задачи и их статусы автоматически сохраняются в `window.localStorage`.
   - При перезагрузке страницы (`F5`) или закрытии браузера все данные остаются на месте.
   - Защита от переполнения квоты и fallback на случай приватного режима браузера.

## 🚀 Дополнительные преимущества (UX & A11y)

- **🎨 Светлая и темная темы**:
  - Автоматическое определение системной темы (`prefers-color-scheme`).
  - Быстрое ручное переключение по кнопке в шапке с сохранением выбора пользователя в памяти.
- **📊 Интерактивная статистика и прогресс-бар**:
  - Наглядная полоса выполнения с динамическим расчетом процентов.
  - Счетчики: «Всего», «В процессе», «Завершено».
- **🔍 Поиск и фильтрация на лету**:
  - Быстрый поиск по названию задачи в реальном времени.
  - Табы быстрой фильтрации: **«Все»**, **«Активные»**, **«Завершенные»** с бейджами количества.
- **✏️ Редактирование задач (Inline Edit)**:
  - Редактирование текста существующей задачи по двойному клику на текст или по иконке карандаша.
  - Поддержка горячих клавиш: `Enter` — сохранить, `Escape` — отменить.
- **📱 Полная адаптивность (Mobile First)**:
  - Идеальное отображение на смартфонах, планшетах и мониторах любого разрешения.
  - Размер интерактивных элементов адаптирован под сенсорные экраны (тач-таргеты от 44–48px).
- **♿ Доступность (A11y)**:
  - Семантическая разметка HTML5 (`<form>`, `<main>`, `<header>`, `<fieldset>`, `<button>`).
  - Явные фокусные кольца `:focus-visible` для удобной навигации с клавиатуры.
  - Озвучивание действий для программ экранного доступа через скрытый `aria-live="polite"` регион.
- **⚡ Нулевые зависимости**:
  - Чистый HTML5, CSS3 и Vanilla JavaScript (ES6+).
  - Открывается мгновенно в любом браузере двойным кликом без сборщиков и `npm install`.

## 💻 Локальный запуск

1. Склонируйте репозиторий или скачайте файлы.
2. Просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari, Opera).

Либо запустите локальный сервер (по желанию):
```bash
# С помощью Python:
python -m http.server 3000

# Либо с помощью Node.js:
npx serve .
```
После чего откройте в браузере: `http://localhost:3000`.
