# ✅ TaskFlow v2.0 — Кастомизируемый список задач с поддержкой Mobile PWA

> Современное, быстрое и глубоко кастомизируемое веб-приложение для управления задачами. Поддерживает установку на смартфон как нативное приложение (Progressive Web App), работу без интернета (Offline-first), палитру акцентных цветов, дедлайны, приоритеты и экспорт/импорт данных.

---

## 🌟 Возможности приложения

### 1. Базовый функционал
- ➕ **Добавление задач** с валидацией, горячей клавишей `Enter` и предотвращением дубликатов.
- ✔️ **Отметка выполнения** с микроанимацией, тактильной отдачей (вибрацией на смартфонах) и пересчетом статистики.
- 🗑️ **Удаление задач** с плавной анимацией (`fade-out`) и кнопка «Очистить завершенные».
- 💾 **Надежное сохранение** всех задач и настроек в `window.localStorage` (данные не пропадают после `F5`).

### 2. Глубокая кастомизация (Customization)
- 🎨 **Палитра акцентных цветов**:
  - 🔵 **Ocean Blue** (морской синий)
  - 🟣 **Royal Purple** (королевский фиолетовый)
  - 🟢 **Emerald** (изумрудный)
  - 🌸 **Neon Rose** (неоновый розовый)
  - 🟠 **Sunset Amber** (янтарный закат)
- 🌓 **Светлая и темная темы**: автоматическое следование системной теме или ручной выбор с сохранением.
- 📐 **Плотность интерфейса**: выбор между *«Комфортным»* (просторным) и *«Компактным»* (вмещает максимум задач на экране) режимами.
- 🔴 **Приоритеты задач**: Высокий 🔴, Средний 🟡, Низкий 🟢 с цветовой индикацией.
- ⏰ **Сроки выполнения (дедлайны)**: с визуальным предупреждением «Срок сегодня!» и подсветкой просроченных задач.
- 🔀 **Сортировка**: по дате (сначала новые/старые), по приоритету, по дедлайну, по алфавиту.
- 💾 **Экспорт и импорт в JSON**: создание резервной копии и удобный перенос задач между устройствами.

### 3. Мобильная версия и PWA (Progressive Web App)
- 📱 **Установка на телефон**: поддержка стандартов PWA (`manifest.json`, иконки, splash screen, запуск без рамок браузера).
- 📶 **Работа офлайн**: встроенный Service Worker (`sw.js`) кэширует ресурсы, позволяя приложению открываться даже без подключения к сети.
- 👆 **Мобильная эргономика**: адаптированные тач-таргеты от 48px, безопасные зоны под системные шторки (`safe-area-inset-bottom`), тактильный виброотклик.
