# 🚀 Инструкция: Публикация на GitHub и запуск рабочего сайта (GitHub Pages)

Данное руководство поможет вам за 2 минуты выложить проект на GitHub и получить **бесплатную ссылку на работающий сайт** (через GitHub Pages).

---

## Шаг 1. Создание репозитория на GitHub

1. Перейдите на сайт [GitHub](https://github.com) и войдите в свой аккаунт (или зарегистрируйтесь).
2. Нажмите зеленый значок **«New»** (или перейдите по ссылке [github.com/new](https://github.com/new)).
3. В поле **Repository name** введите: `todo-list-app`.
4. Оставьте репозиторий **Public** (публичным).
5. Галочки *«Add a README file»*, *«.gitignore»* и *«Choose a license»* **НЕ ставьте** (они уже созданы в проекте).
6. Нажмите кнопку **«Create repository»**.

---

## Шаг 2. Отправка кода в репозиторий

Откройте терминал (PowerShell или Git Bash) в папке проекта:
`C:\Users\Lenovo\.gemini\antigravity\scratch\todo-list-app`

И выполните следующие 3 команды (замените `ВАШ_GITHUB_ЛОГИН` на ваш никнейм на GitHub):

```bash
# 1. Привязка удаленного репозитория
git remote add origin https://github.com/ВАШ_GITHUB_ЛОГИН/todo-list-app.git

# 2. Установка основной ветки main
git branch -M main

# 3. Отправка кода на GitHub
git push -u origin main
```

*(Если вы используете GitHub первый раз, система предложит войти через браузер или ввести Personal Access Token — нажмите подтвердить в браузере).*

---

## Шаг 3. Включение GitHub Pages (получение ссылки на работающий сайт)

1. Откройте ваш созданный репозиторий на GitHub: `https://github.com/ВАШ_GITHUB_ЛОГИН/todo-list-app`.
2. В верхнем меню репозитория нажмите вкладку **Settings** (Настройки).
3. В левом боковом меню перейдите в раздел **Pages**.
4. В блоке **Build and deployment**:
   - В выпадающем списке **Source** выберите **Deploy from a branch**.
   - В выпадающем списке **Branch** выберите ветку `main` и папку `/(root)`.
   - Нажмите кнопку **Save** (Сохранить).
5. Подождите 1–2 минуты, обновите страницу.
6. Вверху раздела появится зеленая плашка с готовой ссылкой на ваш рабочий сайт:
   👉 **`https://ВАШ_GITHUB_ЛОГИН.github.io/todo-list-app/`**
